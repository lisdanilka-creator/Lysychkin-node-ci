# Перевірка практичного заняття 5

Публічний репозиторій: https://github.com/lisdanilka-creator/Lysychkin-node-ci

1. Відкрийте вкладку Actions і останній запуск Node.js CI.
2. Перевірте статус Success та успішні кроки Install dependencies і Build project.
3. У розділі Artifacts завантажте lysychkin-node-build: він містить index.html.
4. Для здачі надішліть викладачу посилання на репозиторій; можна додати посилання на успішний запуск.

Workflow розміщено у .github/workflows/ci.yml. Він автоматично запускається після push у main. Для повторного запуску також доступний Run workflow.
